# Страница поддержки — BTC, XMR, SOL, ETH

Статическая страница с адресами для доната, QR-кодами, пересчётом в доллары и
живой лентой транзакций там, где это технически возможно.

## Адреса и суммы

| Сеть | Адрес | Сумма | Ссылка с суммой | Живая лента |
| --- | --- | --- | --- | --- |
| Bitcoin | `bc1qx4w…dl775gm` | 0.0005 BTC | да (BIP-21) | да |
| Monero | `42coGf…vKnBpU7H4Mjv2tQQ` | 42 XMR | нет | нет |
| Solana | `7vWoJom…78SErN7` | 0.25 SOL | нет | да |
| Ethereum | `0xc4eFE9…BbA27094` | 0.015 ETH | нет | да |

Суммы меняются в `index.html` в элементах `[data-amount]`. Всё остальное
(пересчёт в доллары, пороги эффектов, QR, ссылки) подстраивается само.

## Источники данных для ленты

- **BTC** — публичный API `mempool.space`
- **SOL** — публичный RPC, перебор подписей и транзакций
- **ETH** — два независимых источника, оба без ключа и с CORS:
  1. `eth.blockscout.com/api/v2` — готовая история адреса;
  2. JSON-RPC с перебором последних блоков (нативные переводы не порождают
     логов, поэтому смотреть нужно сами блоки). Окно перебора и позиция
     последнего блока хранятся в localStorage, за один проход не больше
     60 блоков.
- **XMR** — отслеживания нет: собрать входящие транзакции по одному адресу в
  Monero можно только с приватным ключом просмотра, а публиковать его нельзя.

Замечания по провайдерам:

- `api.mainnet-beta.solana.com` отвечает 403 на запросы с заголовком `Origin`,
  то есть из браузера не работает никогда. Основной RPC — `solana-rpc.publicnode.com`.
- `api.coinbase.com` не отдаёт курс XMR, поэтому курсы берутся с CoinGecko,
  а Coinbase используется как запасной источник для пар, которых нет в первом.

## Точность сумм

Суммы хранятся строкой в базовых единицах (сатоши, лампорты, wei) и считаются
через `BigInt`. Это обязательно для Ethereum: 0.015 ETH — это 1.5e16 wei, что
не помещается в `Number` без потери точности. Деление строки на `10^decimals`
собственной функцией, без `toFixed` и без float.

## Дизайн

Оформление собрано по правилам из репозитория
[jakubkrehel/skills](https://github.com/jakubkrehel/skills) (`better-ui`,
`better-typography`, `better-colors`, `better-writing`):

- палитра — рампами в `oklch` с постоянным hue, семантические токены
  поверх примитивов; светлая и тёмная темы переключаются через
  `prefers-color-scheme` (один механизм)
- контраст всех текстовых пар и границ измерен в отрендеренной странице:
  текст ≥ 4.5 (крупный ≥ 3), границы полей и кнопок ≥ 3 — провалов нет
- шрифты: Source Serif 4 для заголовка, Inter для интерфейса, системный
  моноширинный для адреса; `font-optical-sizing`, табличные цифры у
  изменяющихся значений, `text-wrap: balance/pretty`
- движение: только `cubic-bezier(0.2, 0, 0, 1)`, 120 мс на частые
  взаимодействия, `scale(0.96)` на нажатие, полное уважение
  `prefers-reduced-motion`

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Деплой

`.github/workflows/pages.yml` — сборка и публикация через `actions/deploy-pages`.
Сайт: <https://timatigoogl3-code.github.io/donate-btc/>

Внешних зависимостей нет, кроме API: библиотека QR (`vendor/qrcode.min.js`)
вшита в репозиторий, шрифты лежат в `fonts/`.
